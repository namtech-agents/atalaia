# 02 · Validação

Antes de construir, o Atalaia precisa saber se a dor é real. Esta pasta junta o levantamento por entrevista do Marco 1 (12/11/2026).

| Arquivo | O que tem |
|---|---|
| [roteiro-entrevistas.md](roteiro-entrevistas.md) | As perguntas, por tipo de entrevistado (contador, advogado, dono) |
| [mensagens.md](mensagens.md) | Os textos para pedir a conversa e para agradecer depois |
| [lista-entrevistas.md](lista-entrevistas.md) | Quem entrevistar, por código, e o andamento de cada conversa |
| [modelo-anotacao.md](modelo-anotacao.md) | Modelo de uma anotação por conversa (copiar para `entrevistas/E01.md`, `E02.md`...) |

## Meta da semana

- 6 conversas: 3 contadores, 1 advogado, 2 donos de empresa.
- Mensagens saem na segunda, 09/11, às 8h30. Entrevistas de segunda a quarta.
- Na quinta, 12/11, o Model Canvas e os stakeholders (pasta `01-visao`) são ajustados com o que foi ouvido.

## Portão 1 (sexta, 20/11)

Seguir em frente se:

- pelo menos 3 entrevistas confirmaram a dor (já perderam prazo, não olham todas as caixas ou não entendem o que chega), e
- pelo menos 1 pessoa aceitou conversar sobre um piloto pago.

Se não: mais 3 entrevistas na semana 3, com escritórios de advocacia, e o pitch mostra a validação como ela foi.

## Privacidade

O repositório é público. Aqui ninguém aparece pelo nome: cada pessoa vira um código (C1, A1, D1...) e a empresa vira o porte e o ramo. Nome, telefone e o que for confidencial ficam fora do Git. Antes de anotar, pedir licença para usar as respostas no trabalho da faculdade sem identificar ninguém.
